# University Management System

## Description

This is a Java-based University Management System developed to organize and manage student, course, attendance, and login related activities in a simple console-based application.

## Technologies Used

* Java
* IntelliJ IDEA
* Git
* GitHub
* SonarQube for IDE

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open Main.java.
3. Run the Main class.

## Project Structure

Main.java - Starts the program
Front.java - Displays the main menu
Student.java - Handles student details and enrolled courses
Person.java - Stores common user details
Course.java - Handles course details
CourseViewable.java - Interface for viewing courses
Attendance.java - Handles attendance details
Login.java - Handles user login
Lecturer.java - Handles lecturer details
